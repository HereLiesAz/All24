# TODO (Product Roadmap)

This document outlines the product roadmap for the All24 application, including the feature set for the Minimum Viable Product (MVP) and a list of post-MVP features.

## Minimum Viable Product (MVP)

The MVP will focus on the core user experience, including:

*   User account creation and profile.
*   Scrollable home feed of "Top 24" lists.
*   Expandable list items with "The All24 Take" and "The Vitals."
*   The "Vibe Check" system: "Vouch" button and prompted comment submission.
*   Curator-managed "People's Voice" section (manual selection for MVP).

## Post-MVP Features

The following features are planned for future releases:

*   **Creator Takes:** A horizontal carousel showcasing short-form video clips and photo galleries from verified local influencers.
*   **Map View:** A secondary discovery tool that provides a map-based interface for users who have a specific location in mind.
*   **Advanced Profile Features:** The ability for users to create and share personal collections of their favorite spots.
*   **User-to-User Social Features:** The ability for users to follow each other and see their friends' activity within the app.
