# UI/UX

The visual and interactive design of All24 is the physical embodiment of its brand soul. It is sleek, modern, and deceptively minimalistic, revealing layers of depth and personality through interaction.

## Foundations: Color, Typography, and Shape

The core visual identity is established through a carefully considered application of Material 3's foundational subsystems.

*   **Color Palette:** The primary theme is built around "Gaslamp Black" and "Creole Cream," with accent colors drawn from the city's unique visual language. The app will also support Material You's dynamic color theming.
*   **Typography:** A dual type scale is used to be both editorially authoritative and cleanly utilitarian. An emphasized scale with a bold, slightly condensed serif is used for high-impact text, while a baseline scale with a clean sans-serif is used for all body copy and UI labels.
*   **Shape:** The app uses a mix of subtly rounded corners for a modern feel and more distinct shapes for key interactive elements to draw attention and add a touch of unique brand personality.

## The Animation Philosophy

Every interaction is animated with a purpose, using a physics-based motion engine to make the app feel alive and responsive.

*   **Systematic Motion:** The app uses an "Expressive Scheme" for hero moments and a "Standard Scheme" for more utilitarian interactions.
*   **Key Animation Implementations:**
    *   **Spatial Transitions:** A shared element transition between the list feed and the detail view.
    *   **Micro-interactions:** Small, delightful animations on all interactive elements.
    *   **Shape Morphing:** Fluid transformations of UI elements to provide clear, non-verbal feedback.

## Deceptive Minimalism in Practice

The UI appears simple at first glance but reveals its depth through animated interactions.

*   **The Home Feed:** A single, uncluttered column of list item "covers."
*   **The Navigation Bar:** A minimal bottom navigation bar with three clear icons: Lists, Map, and Profile.
*   **The Profile Screen:** A user's personal culinary scrapbook, featuring a grid of "Vouched" places and "Tastemaker" comments.
