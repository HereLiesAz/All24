# Screens

This document provides a detailed breakdown of each screen in the All24 application.

## The Home Feed (Lists Screen)

The primary screen of the app, which displays a visually rich, endlessly scrollable feed of "Top 24" lists. The interface is a single, uncluttered column of list item "covers," with all complexity hidden within the cards themselves.

## The Detail Screen

An expanded, full-screen "article" that is displayed when a user taps a list item. This screen presents a multi-faceted portrait of the establishment, including:

*   **The All24 Take:** The official 150-word review.
*   **Creator Takes:** A horizontal carousel of short-form video clips and photo galleries.
*   **The Vitals:** Address, hours, phone number, and a link to the menu.
*   **The People's Voice:** A curated selection of the most insightful user comments.
*   **"Know Before You Geaux":** A dedicated section for practical, insider tips.

## The Map Screen

A secondary discovery tool that provides a map-based interface for users who have a specific location in mind.

## The Profile Screen

A user's personal culinary scrapbook, featuring a visually engaging grid of all the places they have "Vouched" for, a collection of their "Tastemaker" comments, and any lists they have bookmarked for future reference.
